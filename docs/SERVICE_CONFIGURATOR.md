# Service and parts configurator

The catalog separates labor services from parts. Services describe work, duration, inclusion/exclusion, categories, and compatible vehicle models. Time-based services can share a labor group and declare how many minutes of their own duration cover a common operation. When several services in that group are selected together, MINEX counts the longest declared common operation once, then adds each task's remaining time. The same grouped duration drives the labor estimate and appointment availability. Parts belong to a brand and category and may be OEM, aftermarket, generic, or custom. A part can have technical variants such as roller mass or spring dimensions; structured attributes are stored as normalized values rather than inferred from a product name.

When a rider configures work, the server checks service/category publication, exact compatibility status, option availability, and stock policy. It calculates labor plus selected part prices with integer arithmetic. The resulting booking item freezes the service, brand, SKU, variant, attributes, quantities, prices, discounts, and estimated duration. If compatibility is not backed by approved data, the interface requests workshop confirmation instead of claiming fitment.
